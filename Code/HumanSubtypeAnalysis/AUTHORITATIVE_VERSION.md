# Authoritative Human subtype version

The final Human epithelial and myeloid subtype source data in this package are the Phase12-corrected outputs produced after repair of the Human raw-matrix/filtered-index mismatch.

Use `phase11_human_edger_gsea_corrected.R` followed by the Phase12 eligibility/refit/QA scripts. Earlier Phase7 subtype scripts are retained only because they document the pre-correction analysis chain; they must not be used to regenerate final Supplementary Figures 3–4 without the correction stage.

Authoritative plotting inputs are the files under `SourceData/SupplementaryFigures/SupplementaryFigure3` and `SourceData/SupplementaryFigures/SupplementaryFigure4`.
